# Code of conduct

Starhop follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussions about the work, and do not harass anyone. Maintainers may remove comments, commits or contributors that do not follow it.

To report a problem, use GitHub's **Report content** option on the comment, issue or pull request (it reaches GitHub and the maintainers). If you need to talk to a maintainer privately, open a short issue asking to be contacted, without details. Reports are kept confidential.
